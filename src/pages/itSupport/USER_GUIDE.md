# IT Support — short user guide

## For employees

### Raise a ticket
1. Open **IT Support** in the left menu (or go to Raise).
2. Enter a clear **title**, describe the problem, pick a **category**, and say who is affected (Only me / My team / Whole office).
3. Attach screenshots if helpful (max 10 MB each).
4. Click **Submit**. You will see your ticket number (for example `IT-2026-00001`).

### Follow progress
- Open **My Tickets** to search and filter by status.
- Open a ticket to see the timeline and message the IT team (public comments only).

### When IT marks it Resolved
- If the fix works, click **Confirm fixed** — the ticket closes.
- If it does not work, click **Reopen** within **7 days** and explain what is still wrong.
- If you do nothing for **3 days**, the ticket closes automatically.

---

## For the IT team

### Dashboard
Counts for **New**, **Assigned to me**, **On hold**, **SLA breached**, and **Resolved today**.

### Queue
- Table view with filters (status, priority, category, assigned to) and search.
- Optional **Kanban** board — drag a card to change status (you will be asked for a short remark).

### On each ticket
1. Set **priority** (Critical / High / Medium / Low) — this starts the SLA clock.
2. **Assign** to yourself or a teammate.
3. Work the ticket: **In progress**, **On hold** (waiting for the user — SLA pauses), then **Resolved**.
4. Use **Internal notes** for IT-only discussion; use **Public comments** for messages the employee can see.

### SLA colours
- Green — on track  
- Amber — about 75% of the time used  
- Red — breached (the person assigned and IT managers are notified)

---

## For IT managers (Admin)

### Masters
- Edit **categories** / subcategories.
- Edit **SLA rules** (first response and resolution times per priority).

### Reports
- Tickets by status, priority, and category.
- Export CSV for Excel; use print for a PDF-style report.

### Access
Ask User Management to grant:
- `IT Support (Raise / My Tickets)` for employees  
- `IT Support (Agent Queue)` for agents  
- `IT Support (Admin)` for managers
