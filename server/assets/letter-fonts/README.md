# Letter PDF fonts (LibreOffice)

Bundled for Linux LibreOffice conversion of appointment/offer letters when
Microsoft fonts (Cambria, Aptos Narrow, Calibri, Montserrat) are missing.

| Template font   | Substitute                 | License   |
|-----------------|----------------------------|-----------|
| Cambria         | Caladea                    | Apache 2  |
| Calibri         | Carlito                    | OFL       |
| Aptos Narrow    | Liberation Sans Narrow     | OFL       |
| Aptos / Display | Liberation Sans            | OFL       |
| Montserrat      | Montserrat                 | OFL       |

These files are copied into a private LibreOffice profile at convert time only.
The stored `.docx` template is not modified.
